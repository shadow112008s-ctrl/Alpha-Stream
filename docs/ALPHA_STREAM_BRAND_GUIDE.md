# Alpha Stream visual identity

## Core visual direction
- Black, charcoal and silver monochrome palette based on the owner's supplied brain-and-orbit artwork.
- Use bright silver/white for primary text, controls and selected states; use neutral greys for secondary text, borders and surfaces.
- Avoid electric cyan, red, violet or other colored brand accents in the core application chrome.
- Keep the cinematic dark hero treatment, restrained glass surfaces, rounded content cards and generous spacing from the three supplied UI references.

## App icon
- The launcher artwork is cropped from the owner's supplied monochrome brain-and-orbit image.
- Keep the brain and orbital detail centered; do not include the wallpaper word "THINK".
- Use a pure-black adaptive icon background and the same artwork for regular and round launchers.

## UX consistency
- Apply the same black/silver visual language to Home, Search, Library, Downloads, detail, episode and player surfaces.
- Preserve existing playback, provider, search, watchlist, download, navigation and accessibility behavior.
- Do not add unverified media sources or claim rights to third-party content.
